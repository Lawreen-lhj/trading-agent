# A股交易 Agent · 能力规格（Specs）

> 本目录是项目的**能力规格说明书**，按子系统拆分为多个文件，聚焦「能力行为级」——每个能力**做什么、输入什么、输出什么、如何触发、遵守什么业务规则**，不展开内部私有函数的逐行实现。
> 面向使用者与产品视角；工程实现细节请读源码，操作运维请读根目录 `操作文档.md`。
> 最后更新：2026-11-03

## 系统定位

面向 **A股短线交易**（持股 1 个月内，通常不到一周）的本地量化辅助系统。做分析、给计划、盘中监控、盘后复盘、模拟记账，**不接入任何真实交易通道，不用 LLM 做数值计算**。所有价格、评分、信号都是确定性代码推导，可复现、可回测。


## 全局设计原则（贯穿所有子系统）

1. **纯标准库**：唯一外部依赖 `pyyaml`，不引入 pandas/requests/akshare，避免依赖膨胀。
2. **确定性优先**：指标用代码算不用 LLM 算，每个价格都可复现。
3. **诚实降级**：数据拿不到就返回 `None`/空，标注缺口（`stale_asof`/`sample_suspect`/数据源名），绝不编数。
4. **评分与计划一致**：评分不过观察线就不给买入计划，杜绝"回避却 ready"的自相矛盾。
5. **风控宽于噪音**：止损取更宽者（避免日内正常波动打掉），代价是仓位变小——这是应该付的代价。
6. **不接实盘**：模拟交易只在本地 SQLite 记账，无任何下单通道。
